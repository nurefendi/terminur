# Design

`src/hosts.rs` adds an optional, backward-compatible `identity_file` string and a path resolver that expands only `~/` against the current user's home, rejects other relative paths, and checks readable regular-file metadata without reading key bytes into memory. `src/host_editor.rs` adds a fifth field and validates the optional path. `src/session.rs` constructs SSH arguments in a testable helper, passing `-i` and `-o IdentitiesOnly=yes` only for selected keys; PTY/GPUI threading remains unchanged. `src/main.rs` renders the additional field through the existing label loop and updates the hint. `README.md` documents path-only storage and default agent behavior. Tests cover legacy JSON, valid and invalid paths, argument construction and no-key behavior. Actual key authentication requires manual testing with an authorized host.
