# Compact Hosts workspace

## Motivation
The user's macOS screenshot shows redundant native and custom titles plus an unused introduction row and a tall workspace toolbar. These consume space intended for hosts and the terminal.

## Scope
Keep the native TermiNur titlebar. Collapse the custom topbar, intro row, and workspace toolbar into one compact row with Hosts/session tabs and a functional New host button. Remove duplicate branding in the sidebar. Update PTY grid sizing for the gained space. Keep working host creation and SSH tab behavior.

## Exclusions
No login, SFTP, new navigation features, or custom macOS titlebar. Pending areas remain clearly unavailable.
