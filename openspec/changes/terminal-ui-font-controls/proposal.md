# Proposal: Terminal UI polish and font controls

## Problem
The terminal view has no font zoom controls, while the sidebar, toolbar and status use inconsistent visual emphasis.

## Goal
Introduce accessible, visible font zoom controls and refine the dark desktop visual hierarchy without replacing GPUI or changing SSH transport.

## Scope
Terminal zoom buttons, reset action, responsive grid recalculation and PTY resize, improved terminal toolbar and status treatment, restrained color palette.

## Non-goals
Full theme picker, persistent user preferences, custom fonts or redesigning host editing workflows.
