# TermiNur OpenSpec

Specifications and change proposals for the Rust + GPUI SSH desktop app.

- `specs/`: accepted product behavior (canonical specs).
- `changes/<change-id>/proposal.md`: why and what.
- `changes/<change-id>/spec.md`: testable requirements and scenarios.
- `changes/<change-id>/design.md`: implementation architecture.
- `changes/<change-id>/tasks.md`: executable checklist.
- `changes/<change-id>/verification.md`: CI and runtime evidence.
- `archive/`: completed and accepted changes.

The workflow instructions live in `.agents/skills/openspec/SKILL.md`.
Quality-review instructions live in `.agents/skills/sonarqube/SKILL.md`.

These repository skills are documentation for compatible coding agents; they do not install ChatGPT skills or activate a SonarQube server.
